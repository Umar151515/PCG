Библиотека pcg для создания консольных игр на Python
Эта библиотека, разработанная 2 года назад, предоставляет инструменты для создания консольных игр на Python. Она была создана с целью углубить понимание объектно-ориентированного программирования (ООП) в Python.

Библиотека предназначена только для работы в Windows.

Решение проблем с отображением символов (Windows): Если вы столкнулись с неправильным отображением символов при запуске, выполните следующие действия:
Щелкните правой кнопкой мыши по заголовку окна PowerShell или командной строки.
Выберите пункт "Параметры".
В разделе "Приложение терминала по умолчанию" установите значение "Узел консоли Windows".
Сравнение с Pygame
Библиотека pcg предоставляет схожий с Pygame подход к разработке игр, но ориентирована на вывод в текстовой консоли.

Для начала работы необходимо импортировать библиотеку pcg:

```Python
import pcg
```

Для взаимодействия с консолью необходимо создать экземпляр класса WindowConsole. При создании указываются ширина и высота консоли в символах:

```Python
console = pcg.WindowConsole(120, 40)
```
Внимание: При создании нового объекта WindowConsole происходит переназначение предыдущего объекта. Например, если вы создадите второй объект console2, переменная console будет ссылаться на console2:
```Python
console2 = pcg.WindowConsole(140, 60)
# Теперь переменная console ссылается на тот же объект, что и console2
```

Класс TextImage предназначен для хранения текстовых данных и информации о его размерах. Создать объект TextImage можно следующим образом:
```Python
text = pcg.TextImage("##\n##")
```
В данном примере text будет представлять собой блок из четырех символов #, расположенных в два ряда по два символа.

Для отображения объекта TextImage на консоли используется функция blit() из модуля pcg.draw. Синтаксис функции следующий:
```Python
pcg.draw.blit(destination_console, source_text_image, position)
```
destination_console: Объект WindowConsole, на котором будет отображаться текст.
source_text_image: Объект TextImage, который необходимо отобразить.
position: Координаты верхнего левого угла текста на консоли. Может быть кортежем (x, y) или объектом Rect.

Для предотвращения мгновенного закрытия консоли после отрисовки необходимо использовать бесконечный цикл:
```Python
while True:
    pcg.draw.blit(console, text, (20, 60))
    console.update() # Обновляет отображение консоли
```
Функция console.update() необходима для фактического отображения изменений в консоли.

Управление положением и размерами: класс Rect
Класс Rect используется для хранения координат и размеров прямоугольной области.

Для автоматического получения объекта Rect, соответствующего размерам объекта TextImage, используется метод get_rect():
```Python
rect = text.get_rect()
```

Объект Rect также можно создать вручную, указав координаты верхнего левого угла, ширину и высоту:
```Python
rect = pcg.Rect(x, y, size_x, size_y)
```

Координаты объекта Rect можно изменять напрямую через его атрибуты:
```Python
rect.x_cor = new_x_coordinate
rect.y_cor = new_y_coordinate
```

Для получения текущих координат используются те же атрибуты:
```Python
current_x = rect.x_cor
current_y = rect.y_cor
```

Объект Rect предоставляет и другие полезные свойства для работы с положением и границами:

x_center, y_center: Координаты центра прямоугольника.
right, bottom: Координаты правой и нижней границ.

Также доступны свойства, возвращающие координаты ключевых точек в виде кортежей (x, y):

top_left
top_right
bottom_left
bottom_right
top_center
bottom_center
right_center
left_center
center

Вместо передачи кортежа координат в функцию blit(), можно передать объект Rect:
```Python
pcg.draw.blit(console, text, rect)
```

Для создания анимации движения необходимо изменять координаты объекта Rect в цикле отрисовки:

```Python
rect.x_cor += 0.1 # Сдвиг текста вправо на 0.1 символа за итерацию
```
При запуске такого кода текст будет двигаться вправо, оставляя за собой "след" из-за того, что предыдущие кадры не очищаются.

Для очистки содержимого консоли перед отрисовкой нового кадра используется метод fill() объекта WindowConsole. В качестве аргумента передается символ, которым будет заполнена вся консоль:

```Python
console.fill(" ") # Заполнение консоли пробелами
```

Чтобы текст возвращался в начало экрана после выхода за его правую границу, можно добавить следующую логику в цикл:

```Python
if rect.x_cor > console.size_x: # Если правая сторона текста вышла за ширину консоли
    rect.right = 0 # Установить правую границу текста в начало (x=0)
```

Полный пример кода с движущимся и возвращающимся текстом:
```Python
import pcg

console = pcg.WindowConsole(120, 40)

text = pcg.TextImage("##\n##")
rect = text.get_rect()

rect.y_cor = 20

while True:
    console.fill(" ")  # Очистка консоли
    pcg.draw.blit(console, text, rect)
    rect.x_cor += 0.1
    if rect.x_cor > console.size_x:
        rect.right = 0

    console.update()
```
Этот код создаст окно консоли, отобразит в нем блок ## на середине высоты, который будет плавно двигаться вправо и возвращаться к левому краю экрана после достижения правой границы.
